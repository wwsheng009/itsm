# 238 demo 部署证据：预检驱动激活/结项入口 + 阶段门深链（2026-10-18，1.8.0-dev.12c2d7d2）

## 优化内容

1. **顶部阶段门徽标**（详情页）
   - 规划中：立项门徽标；进行中/已暂停：结项门徽标。
   - 状态优先级：`已通过`（success）/ `审批中`（processing）/ `就绪`（success，预检通过但未提交）/ `待补 N 项`（warning）。
2. **激活/结项前置拦截（预检驱动）**
   - 预检已加载时，若目标门不处于 `passed`：不调用后端，直接切到「阶段门」并提示：
     - 未提交 → 「立项门尚未提交，请先在阶段门提交」；
     - 审批中 → 「立项门审批中，请等待通过后再激活」；
     - 已拒绝/其他 → 「立项门尚未通过，请先在阶段门处理并重新提交」。
   - 预检未就绪（阻塞项 >0）同样拦截并提示待补数量。
   - 结项按钮复用同一逻辑（结项门），业务阻塞项/结项清单仍由后端兜底。
3. **阶段门深链**
   - 详情页支持 `/projects/:id?tab=gates` 直接打开阶段门。
   - 列表页激活失败弹窗按钮改为「去阶段门处理」，直达 `?tab=gates`。
4. **错误透出**
   - 详情页转场失败剥离 `[RID]` 后展示后端真实消息；阶段门门禁错误自动切 Tab 并刷新预检。
