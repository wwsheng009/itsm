# 仪表盘

## 适用场景

- 每日开工先看"今天最需要关注什么"；
- 管理者查看趋势与团队负载。

## 关键概念

- **SLA 风险**：临近违约/已违约工单占比；
- **未解决事件**：按级别与影响面聚合；
- **待批变更**：需要 CAB 评审的变更数量；
- **团队负载**：按分派人与处理时长分布。

## 常用操作

1. 浏览卡片确认异常项（红色/黄色标识）；
2. 点击卡片钻取到对应列表，对高风险项优先处置；
3. 用 AI 助手生成当日只读汇总，作为交接/例会输入。

## 常见问题

- **指标口径在哪里？** 各卡片右下角的说明或悬停提示；SLA 指标见 SLA 监控页；
- **数字与列表不一致？** 卡片为聚合口径（按统计窗口），列表为明细口径；如需一致性排查请联系平台管理员；
- **可以订阅日报吗？** 通知中心后续批次提供订阅能力。

## AI 助手可用动作（页面建议卡）

- 「今天最需要关注什么？」：只读汇总 SLA 风险 / 未解决事件 / 待批变更；
- 「SLA 风险摘要怎么看？」：解释各指标含义与介入信号。
