# 服务请求

## 适用场景

- 查看自己提交的服务请求、审批状态与交付进度；
- 判断账号开通、设备故障等问题应走服务请求还是事件单；
- 审批人处理待审批的服务请求。

## 关键概念

- **服务请求**：可预约、可审批的标准服务（如开通 VPN、邮箱或业务账号）；
- **事件单**：已经发生的故障或服务中断（如笔记本无法开机、网络不可用）；
- **审批流**：服务请求按目录条目配置路由；审批通过后才进入开通/交付；
- **交付状态**：提交、审批中、开通中、已交付等阶段决定下一步动作。

## 常用操作

1. 在「我的请求」查看进度，按状态筛选并打开详情；
2. 新建请求前先确认服务条目与所需材料；
3. 审批人从「待审批」页签处理请求并填写意见；
4. 进度停滞时，在详情中查看当前审批层与交付任务。

## 常见问题

- **VPN、邮箱、业务账号一起申请，要拆单吗？** 建议按交付责任与审批链拆分；同一服务条目可合并，不同资源类型分开更易跟踪。
- **设备坏了走哪种单？** 已发生的硬件/软件故障通常走事件单；更换、领用或标准化开通走服务请求。
- **AI 会直接提交吗？** 不会直接提交。AI 只生成建议或字段草稿；写操作必须进入人工审批，审批通过后才执行。
- **“第二张单”指哪一张？** AI 会在指代不唯一时先列候选（类型、编号、标题）并要求确认，不会自行猜测。

## AI 助手可用动作（页面建议卡）

- 「查我的请求进度」：只读汇总最近请求及下一步；
- 「我要开通账号」：判断应选的服务类型与所需信息；
- 「我的设备坏了」：判断事件单/服务请求并提示补充设备信息。
