# 知识库（检索 / 新建文章）

## 适用场景

- 坐席检索解决方案、自助用户查找操作指引；
- 把解决过的工单沉淀为知识文章，减少重复劳动。

## 关键概念

- **引用来源**：AI 回答会给出引用（文章标题/片段/相关度），请以引用原文为准；
- **复核时效**：文章可设置复核周期；过期的知识不会被 RAG 引用（`valid_until`/复核逾期）；
- **权威等级**：官方标准/唯一真相源的文章在检索排序中优先。

## 常用操作

1. **检索**：用自然语言描述问题（现象+环境），或按分类浏览；
2. **新建文章**：
   - 从工单/事件页"补充为知识文章"带入正文；
   - 或在新建页让 AI 把要点整理成草稿（**不自动发布**）；
3. **发布**：补齐适用场景/步骤/验证后提交评审发布；
4. **维护**：到期前复核，更新版本；失效内容及时归档。

## 常见问题

- **为什么检索不到？** 检查文章是否已发布、是否在时效范围内、分类权限是否覆盖；
- **AI 回答没有引用？** 说明知识库未命中，可换关键词或先补一篇文章；
- **谁负责维护？** 文章 owner/知识管理员；平台按季度核对覆盖率与过期清单。

## AI 助手可用动作（页面建议卡）

- 「怎么快速找到相关方案？」：给出检索式描述建议；
- 「自助解决问题的入口在哪里？」：推荐常见问题的自助路径。
