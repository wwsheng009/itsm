# AI 助手（对话工作区）

## 适用场景

- 就当前业务问题直接提问（如"这个问题的标准处置流程是什么？"）；
- 让 AI 做只读分析（汇总、影响面、历史相似案例）或产出草稿（答复/文章/计划）。

## 关键概念

- **入口上下文**：从工单/事件/CI 详情页的「问 AI」进入时，会携带对象上下文（页面上方显示上下文条）；
- **工具过程可见**：AI 调用工具的过程（查询、计划）会在消息中展示；写动作会弹出**确认卡片**；
- **引用来源**：回答附引用（知识文章/实体），点击可展开片段；
- **停止生成**：流式输出中可随时停止，不影响已产生的内容。

## 常用操作

1. 页面右下角悬浮球打开 **AI 助手面板**（或 `Ctrl/Cmd+I`）；
2. 点击页面建议卡（任务卡/问题卡）零输入发起，或直接输入问题；
3. 涉及写动作时：在确认抽屉中审阅参数 → 确认/拒绝；
4. 需要长期沉淀时：把回答"补充为知识文章"。

## 常见问题

- **AI 会直接改数据吗？** 不会自动写：写动作必须人工确认（审批链不变）；
- **回答里的数据来自哪里？** 工具调用（实时查询）+ 知识库检索（附引用）；
- **响应很慢？** 复杂分析会调用多次工具；可先看已返回的部分或停止生成后换更具体的问题。
