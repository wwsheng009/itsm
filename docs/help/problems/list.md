# 问题管理

## 适用场景

- 多张工单指向同一根因时，立项问题做根因分析与永久修复；
- 维护已知错误（Known Error）与临时规避方案。

## 关键概念

- **问题 vs 工单**：问题是根因视角，工单是事件/请求视角；一个问题可关联多张工单；
- **已知错误**：根因已定位但修复未上线，需记录规避方案；
- **调查步骤（RCA）**：假设 → 验证 → 结论，过程留痕。

## 常用操作

1. 在列表中筛选未关闭问题，确认关联工单与影响趋势；
2. 进入问题详情推进调查（记录假设与验证证据）；
3. 定位根因后创建变更实施修复，并更新已知错误状态；
4. 相关问题全部关闭后发起复盘。

## 常见问题

- **根因线索怎么找？** 从已知错误与历史工单中聚类现象，结合 CI 关系与近期变更；
- **可以只记录不修复吗？** 可以（已知错误状态），但需给出规避方案与复评时间；
- **趋势在哪里看？** 问题趋势页（`/problems/trends`）提供增量与重复率。

## AI 助手可用动作（页面建议卡）

- 「已知错误的根因线索怎么找？」：给出排查路径（从已知错误/历史工单/近期变更入手）。
