# 变更（新建与详情）

## 适用场景

- 变更经理/评审人（CAB）查看待批与进行中的变更；
- 实施人提交变更并准备影响面与回滚方案。

## 关键概念

- **风险等级**：由影响范围、可回滚性、历史失败率综合判断；
- **影响面**：关联 CI 的上下游、关联工单与历史事件（可用 AI 生成**只读**分析计划）；
- **CAB 证据**：影响面分析、回滚方案、验证与监控安排。

## 常用操作

1. **新建变更**：填写变更内容、窗口期、回滚方案；不确定时用建议卡"梳理风险与回滚方案"；
2. **提交评审**：补齐 CAB 所需证据（影响面分析计划可一键生成）；
3. **实施与验证**：按窗口执行，完成后填写验证结论；
4. **复盘（PIR）**：记录偏差与改进项。

## 常见问题

- **标准变更/紧急变更怎么区分？** 见流程配置（标准变更走预授权模板，紧急变更需事后补评审）；
- **影响面在哪里看？** 变更详情页可生成影响分析计划（只读，引用 CI 关系与历史事件）；
- **AI 会自动批准吗？** 不会；审批链与 CAB 规则不变。

## AI 助手可用动作（页面建议卡）

- 「生成影响分析计划」（变更详情/CI 详情）：只读分析，产出计划与证据引用；
- 「CAB 需要哪些证据？」：列出当前变更仍需补充的材料；
- 「本周变更概览」（列表页）：只读汇总待批与进行中变更。
