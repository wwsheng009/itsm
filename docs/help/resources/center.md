# 资源中心（Agent Skills）

## 适用场景
- 用户查看当前环境可分发的 ITSM Agent Skills 及其版本、大小和校验信息。
- 用户下载单个技能包或全量包，交由自己的 code agent 按标准方式发现和使用。
- 管理员核对分发清单、构建来源和文件哈希。

访问路径：`/skills`，页面标题为“资源中心 · Agent Skills”。

## 关键概念
- **Skill 内容包**：遵循 `SKILL.md + references/ + scripts/ + _lib/` 的标准目录结构，面向 Claude Code、Codex、aicli 等 code agent。
- **内容本位**：页面只提供技能内容和兼容格式，不替用户决定安装目录；具体发现机制以目标 agent 的官方说明为准。
- **分发清单**：展示技能名称、版本、描述、文件大小、SHA-256、构建提交和打包时间，可用于核对下载内容。
- **使用前提**：目标 ITSM 环境可达、Python 3.8+（CLI 使用标准库）以及具有相应业务权限的账号。

## 常用操作
1. 打开资源中心，等待分发清单加载；页面提示“分发面未配置”时联系管理员配置服务端 Skills 分发目录。
2. 阅读技能卡片中的描述、版本和大小，选择需要的技能点击“下载”。
3. 需要全部技能时点击“下载全量包”；也可以使用“复制链接”获取对应下载命令。
4. 下载后按包内 `SKILL.md` 和目标 agent 的官方规则放置或导入，不要假定所有 agent 使用同一目录。
5. 对完整性有要求时，使用页面展示的 SHA-256 与下载文件进行校验；清单更新后点击“刷新”重新读取。

## 常见问题
- **为什么页面提示未配置？** 服务端尚未挂载 Skills 分发目录或分发接口不可用，需要平台管理员处理。
- **下载后应该放在哪里？** 由你的 code agent 决定，本页面不指定统一安装位置，请查阅对应 agent 的技能发现规则。
- **技能可以绕过 ITSM 权限吗？** 不可以，技能调用仍需要可达环境和具备相应权限的账号。

## AI 助手可用动作
- 可通过页面 AI 助手查询 Skill 包结构、下载与校验说明。
- AI 不替用户安装技能、修改 agent 配置或绕过目标环境权限。
