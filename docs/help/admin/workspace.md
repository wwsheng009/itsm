# 系统管理

## 适用场景
- 平台管理员查看系统运行概览、健康状态、近期活动与快捷入口。
- 管理员维护用户、角色、部门、团队、租户、菜单和权限。
- 管理员配置 CAB、CMDB 类型、服务目录、SLA、通知、连接器与系统参数。

访问路径：`/admin`。用户、角色、租户、CAB、CMDB 类型和系统设置等子页面均从系统管理进入，具体可见项由权限决定。

## 关键概念
- **系统概览**：用于查看系统指标、健康状态和近期活动，不是业务报表；指标异常时应进入对应管理页或审计日志核查。
- **用户与角色**：用户是登录与操作主体，角色决定功能权限；数据范围还可能受部门、团队、客户和租户限制。
- **租户隔离**：租户配置仅对当前租户生效，跨租户修改前必须确认当前上下文。
- **CAB**：维护变更咨询委员会名单，不等同于具体变更审批流程。
- **CMDB 类型**：定义配置项属性结构；存在 CI 实例时不能直接删除类型，应先迁移或清理实例。
- **系统参数**：邮件、认证、SSL/TLS、AI 等配置影响范围较大，保存前应核对环境和回退方式。

## 常用操作
1. 进入系统管理首页，先查看运行概览、健康状态和近期活动，再从快捷入口进入目标配置页。
2. 维护用户或角色时，先确认账号、角色和数据范围；保存后用测试账号验证菜单与操作权限。
3. 维护部门、团队、菜单或路由规则时，先检查上下级和权限码，避免删除仍被引用的配置。
4. 维护 CAB、CMDB 类型、服务目录或 SLA 配置时，先核对现有业务引用，再执行新增、编辑、启停或删除。
5. 修改系统参数前记录原值和影响范围；密码等敏感字段保存后通常不回显明文，不要通过文档传播。
6. 配置完成后刷新页面并验证一项实际业务流程，必要时在审计日志中核对操作结果。

## 常见问题
- **为什么看不到某个管理入口？** 当前角色没有对应权限，或入口未分配给当前租户/菜单配置。
- **为什么配置保存后不生效？** 检查是否保存到正确租户、是否需要启用或重新登录，并核对缓存与部署级回退配置。
- **为什么无法删除类型、部门或规则？** 目标可能仍被业务数据引用；先处理引用关系，不要强行删除造成数据失联。

## AI 助手可用动作
- 可通过页面 AI 助手查询系统管理入口、权限和配置边界。
- AI 不自动创建管理员、修改角色权限或保存系统参数；高风险配置由管理员人工执行。
