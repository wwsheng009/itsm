# 服务目录

## 适用场景

- 用户按目录自助提交服务请求（如申请账号、开通权限、领用设备）；
- 管理员维护目录条目与表单字段。

## 关键概念

- **目录条目**：一类可重复申请的服务（含表单、审批链、SLA）；
- **表单字段**：由管理员配置，决定申请时需要提供的信息；
- **审批链**：按条目配置自动路由（部门负责人/资源 owner 等）。

## 常用操作

1. 浏览或搜索目录条目，阅读条目说明与所需材料；
2. 提交申请：填写表单 → 提交 → 跟踪审批进度；
3. 审批人处理待办；完成后申请人可在"我的请求"查看结果。

## 常见问题

- **该选哪个服务？** 用建议卡"该选哪个服务？"描述场景，AI 帮你判断并说明理由；
- **条目找不到？** 可能未发布或权限范围不可见，请联系服务台；
- **表单字段填错？** 提交前可修改；已提交的走审批备注沟通。

## AI 助手可用动作（页面建议卡）

- 「该选哪个服务？」：根据问题描述推荐条目并解释判断依据（只读建议）。
