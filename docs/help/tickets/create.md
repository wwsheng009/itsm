# 创建工单（含 AI 创建）

## 适用场景

- 员工报障或提出服务请求；
- 坐席代客建单；
- 用自然语言描述需求，让 AI 生成字段草稿（AI 创建工单）。

## 字段填写要点

| 字段 | 要点 |
|---|---|
| 标题 | 一句话描述"谁 + 什么问题 + 影响"，例如"财务部多台电脑无法访问 NAS" |
| 描述 | 现象、开始时间、影响范围、已做的尝试 |
| 分类 | 不确定时先用 AI 建议，提交后仍可调整 |
| 优先级/影响 | 影响多人或核心系统时给出更高优先级，并说明依据 |
| 附件 | 截图/日志能显著缩短定位时间 |

## AI 创建工单（推荐路径）

1. 进入「AI 创建工单」页；
2. 用自然语言描述问题（例如"打印机显示缺纸但实际有纸"）；
3. AI 生成字段草稿，逐项确认/修改后提交；
4. 提交前页面会展示最终字段，**不会自动提交**。

## 常见问题

- **不知道选哪个分类？** 选"其他"并在描述里说明，分诊阶段会调整；
- **能改已经提交的工单吗？** 可以，在工单详情中编辑并留痕；
- **AI 建议与我的判断不一致？** 以人工为准；差异可在备注中记录。

## AI 助手可用动作（页面建议卡）

- 「帮我起标题与描述」：引导补齐关键信息，给出可编辑草稿；
- 「这些字段该怎么填？」：说明分类/优先级/影响范围的判断口径。
