# 工单列表

## 适用场景

- 服务台坐席查看/分派待处理工单；
- 按状态、优先级、SLA 风险筛选需要优先处理的工单。

## 关键概念

- **状态**：新建 → 处理中 → 待用户 → 已解决 → 已关闭；
- **优先级**：一般由分诊建议给出（紧急/高/中/低），可人工调整；
- **SLA**：列表中的剩余时间来自 SLA 定义；临近违约会高亮提示。

## 常用操作

1. 用筛选器限定范围（状态 / 优先级 / 分派人 / 时间窗口）；
2. 点击行进入**工单详情**（可让 AI 给出分诊与答复草稿）；
3. 批量场景：先筛选再逐条处理；批量操作能力见后续批次说明。

## 常见问题

- **为什么看不到某些工单？** 与数据范围（部门/团队/客户）和角色权限有关；
- **列表为空？** 检查筛选条件或与客服管理员确认分派关系；
- **优先级能改吗？** 可以，但若与分诊建议不一致，请在工单备注中说明理由。

## AI 助手可用动作（页面建议卡）

- 「汇总我待处理的工单」：只读汇总（数量、优先级分布、临近 SLA 的项）；
- 「如何优先处理这些工单？」：按优先级与 SLA 风险给出建议顺序。
